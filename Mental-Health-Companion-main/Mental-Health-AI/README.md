# AI-Based Mental Health Companion

This project is a web-based AI mental health companion application designed to detect early signs of stress, anxiety, or depression through text analysis, voice patterns, and behavioral tracking. It provides coping mechanisms, resources, and connects users with professional help when needed.

## Technology Stack

- Frontend: React with Tailwind CSS
- Backend: Node.js with Express
- AI Integration: OpenAI API for text analysis
- Voice Analysis: Integration with voice analysis API/library
- Database: MongoDB for behavioral tracking and user data
- Authentication: User authentication for personalized experience

## Project Structure

- `/frontend`: React application with Tailwind CSS
- `/backend`: Express API server with routes for AI analysis, user data, and authentication
- `/shared`: Common utilities or types (if needed)

## Features

- Text input for mental health check-ins with AI analysis
- Voice recording and analysis for emotional state detection
- Behavioral tracking dashboard to log mood, activities, and sleep patterns
- Coping mechanisms and resource pages based on AI analysis
- Connection to professional help via contact forms or resource links
- Responsive and accessible UI design
